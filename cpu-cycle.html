How Does a Computer Actually Think?

Every single program on your smartphone, laptop, or supercomputer is broken down into simple instructions. The CPU (Central Processing Unit) continuously repeats a fundamental 3-stage loop billions of times per second: Fetch the instruction from RAM, Decode what it means, and Execute the operation.

Fetching Instruction from RAM

The CPU retrieves the next instruction from RAM. The Program Counter (PC) holds memory address 0x01. This address is sent over the Address Bus to RAM. RAM places the instruction ADD 5, 3 onto the Data Bus, which is loaded into the Instruction Register (IR). The PC then automatically increments to prepare for the next instruction.

Mastering the 3 Stages of the Machine Cycle

Understanding what physically happens inside the silicon at each stage.

01
📥

1. The Fetch Stage

Retrieving the instruction from RAM into the CPU

The CPU cannot execute an instruction until it brings it into its internal registers. The Program Counter (PC) always stores the memory address of the next instruction to run.

  • Step 1: Address in PC is copied to the MAR (Memory Address Register).
  • Step 2: Address travels across the Address Bus to RAM.
  • Step 3: RAM reads the instruction and places it onto the Data Bus.
  • Step 4: The instruction enters the MDR and is copied into the IR (Instruction Register).
  • Step 5: The PC automatically increments (e.g. PC = PC + 1) to point to the next instruction in sequence.
Real-World Analogy: A chef reading the next recipe card from a recipe box and laying it on the kitchen counter.
02
🔍

2. The Decode Stage

Interpreting what operation the instruction requires

The raw binary stored in the Instruction Register (IR) is split into two distinct parts: the Opcode (Operation Code) and the Operands (the data or memory addresses).

  • Opcode: Tells the CPU what to do (e.g. ADD, SUB, LOAD, STORE, JUMP).
  • Operands: Tells the CPU who or where the data is (e.g. numbers 5 and 3).
  • Control Unit (CU): The CU's instruction decoder energizes specific internal control wires, preparing the ALU and registers for computation.
Real-World Analogy: The chef reading the recipe instructions: "Add 5 grams of sugar to 3 grams of salt" and grabbing the ingredients.
03
⚡

3. The Execute Stage

Performing the operation and storing the output

The operation is carried out by the hardware circuits. For arithmetic operations like ADD, the Arithmetic Logic Unit (ALU) performs binary addition on the inputs.

  • ALU Operation: Inputs 5 and 3 are sent to the ALU logic gates.
  • Calculation: Logic gates compute 5 + 3 = 8.
  • Accumulator (ACC): The output 8 is saved into the Accumulator register.
  • Status Flags: Flags like Zero (Z), Carry (C), and Negative (N) are updated based on the result.
  • Repeat: The CPU loop finishes and restarts at Fetch for the next instruction!
Real-World Analogy: The chef actually mixing the sugar and salt together in a bowl to produce the final mix.
Interactive Hardware Glossary

Key CPU Registers & Components

Click on any component to explore its full name, role, and practical computer science significance.

Register

Program Counter (PC)

Holds the memory address of the next instruction waiting to be executed.

Key fact: Increments automatically during the fetch phase so the CPU knows where to continue next.
Register

Memory Address Register (MAR)

Stores the memory address in RAM that is currently being read from or written to.

Key fact: Connects directly to the physical Address Bus lines.
Register

Memory Data Register (MDR)

Holds the data or instruction that has just been fetched from, or is about to be sent to RAM.

Key fact: Also known as the Memory Buffer Register (MBR); connected to the Data Bus.
Register

Instruction Register (IR)

Holds the actual copy of the instruction currently being decoded and executed.

Key fact: The Control Unit inspects the bits in the IR to decode Opcode and Operands.
Core Unit

Control Unit (CU)

The "conductor" or "brain" of the CPU. Coordinates all data movements and component timing.

Key fact: Decodes opcodes and emits electrical control signals to the ALU, RAM, and registers.
Core Unit

Arithmetic Logic Unit (ALU)

The primary digital calculator of the CPU. Performs arithmetic (+, -, ×) and logic (AND, OR, NOT).

Key fact: Built using digital logic circuits like Full Adders, Multiplexers, and Shifters.
Register

Accumulator (ACC)

A high-speed temporary storage register that holds the immediate output of the ALU's calculations.

Key fact: When 5 + 3 is computed, the resulting 8 is immediately saved in the ACC.
Pathway

System Buses (Address, Data, Control)

High-speed electrical highways that connect CPU components to each other and to RAM.

Key fact: Address Bus is one-way (CPU → RAM); Data Bus is bidirectional (CPU ↔ RAM).
